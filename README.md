# Weekframe-releases
Release artifacts and metadata for Weekframe
Weekframe
A private, self-hosted weekly planner for Windows. Runs on your own computer; your goals never leave it unless you turn on cloud AI.

Download: the latest installer is on the Releases page. Windows may say "Windows protected your PC" because the installer is not code-signed yet: click More info, then Run anyway. Compare the file's SHA-256 with the .sha256 file next to it.

Weekframe is intended for adults aged 18 and older. Use at your own risk. This repository holds only the installers; to report a problem privately use the Security tab.
